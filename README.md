# SSBProject

스파르타 내일배움캠프의 세 번째 팀 프로젝트 과제입니다.  
팹의 Platform Fighter Starter Kit 템플릿을 기반으로 리슨 서버를 활용한 멀티 게임을 제작해야했습니다.

5명이서 한 조가 되어 협업해서 만들었습니다.  
팀장 김선국, 팀원 김강현, 김인겸, 박선우, 이수빈으로 이루어져있습니다.

## 개발 환경

+ IDE: Visual Studio 2022
+ Unreal Engine: 5.5.4
+ C++ 17

## 빌드/실행 방법

`SSBProject` 폴더의 `SSBProject.sln`을 실행시켜 사용하고 있는 IDE에서 빌드 > 솔루션 빌드를 합니다.  
혹은 같은 디렉토리의 `SSBProject.uproject`를 실행시킵니다.

## 의존 라이브러리/패키지

사용하고 있는 라이브러리 등 추가로 사용한 것은 없습니다.

## 사용한 개발자 도구

+ Git LFS

## 프로젝트 개요

### 개발 기간

2025.04.02 ~ 2025.04.18

### 게임 설명

리슨 서버를 기반으로 구현돼있으며, 에디터로 플레이할 경우 플레이할 클라이언트 수를 직접 지정하여 게임을 플레이해주어야 합니다.

메인 메뉴에서 싱글, 멀티 플레이 대전, 멀티 플레이 협력, 옵션 등을 선택할 수 있습니다.

멀티 플레이 대전의 경우 총 네명까지 접속 가능하며, 짝수로 접속한 경우에만 시작할 수 있습니다.

멀티 플레이 협력의 경우 아군 플레이어가 두 명, AI가 둘로 게임이 진행됩니다.
